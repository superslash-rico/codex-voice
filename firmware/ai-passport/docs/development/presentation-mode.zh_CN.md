# Codex 配件演示模式

固件 `0.4.0-presenter` 通过既有加密工牌 GATT 连接提供翻页控制，需要配套 Mac 应用，并非独立 HID 键盘。主机测试、构建不代表实机验收。

长按下键 1500 毫秒请求进入／退出演示模式。BSP 的 500 毫秒长按回调仅抑制后续短按，应用轮询实际保持状态，在 1500 毫秒触发一次。按键回调只更新原子变量并投递事件。

演示模式中，上下键请求上一步／下一步，屏幕调暗后的第一次短按也翻页。新提醒更新待处理数量，不改变按键含义或替换演示页面。确认键不接手或打开任务，听写暂停。长按上键仍打开本地菜单，菜单中的上下键仅用于导航；需先退出演示模式再使用提醒菜单操作。

Mac 提供就绪、焦点暂停、缺少权限、准备中四种状态。提醒引擎确认停止播报后，才报告就绪。发送完整的左右键按下／松开事件前，再次核对前台应用身份。首版识别 PowerPoint、Keynote 和 WPS 的 Mac 主应用标识，可固定选择目标。用户需自行开始放映并将焦点留在放映窗口。本功能不读取幻灯片内容、放映状态或页码。

## 协议扩展

- 工牌 `hello`：`presenter: true`，`presenterSession` 为随机的 16 位十六进制启动身份。
- 电脑 `state`：`presenterSupported`、`presenter`、`presenterReady`、`presenterStatus`（0 就绪、1 焦点、2 权限、3 准备中）、`presenterTarget`（0 自动、1 PowerPoint、2 Keynote、3 WPS）、`presenterLease`（16 位十六进制）。
- 工牌请求：`v:1`、`type:"presenter"`、匹配的 `epoch`、`session`、`lease`、正递增序号 `seq`（不大于 INT32_MAX），`op` 为 `enable`、`disable`、`previous` 或 `next`。

电脑随状态签发短时凭据，拒绝超过 2.5 秒、重复、旧连接或旧启动、不支持的操作、错误焦点、权限不足或未确认静音的请求。合法但被阻止的序号被消费，不保留重试。工牌拒绝使用过期状态发送。翻页不重发、不存储到重连后执行。同一启动的重复 HELLO 不重置电脑端去重。断开、主机重启或休眠清除手动模式，重连不自动恢复。

电脑和固件均拒绝演示模式中的提醒播放。Mac 临时抑制自动提醒面板，保留待处理任务；提醒引擎使用可续期的八秒运行时租约，不改既有偏好和次数，拥有者停止续期后结束静音。协议不代替用户审批任何 Codex 请求。

LVGL 演示页面采用适合讲台的深色配色，大尺寸纵向上一页／下一页控制区，下一页以蓝色强调，并提供状态标识和不泄露任务内容的待处理数量。圆角控制区与箭头直接绘制，与互斥的任务页面共用标签，保留既有 32 KiB LVGL 配置。它沿用电量头部，不复用演示／硬件测试界面。新增固定中文须验证生成字体覆盖。获准分段更新时，保留既有分区、配对、昵称和宠物资源。
