- 补上 Computer Use 应用访问确认卡片的可选提醒。默认关闭，用户开启并授予辅助功能后才识别当前 Codex 窗口的真实授权控件；普通命令审批和自动审批过滤保持原流程。
- 199项 Python 测试通过，包含新来源的提醒、接手去重、卡片关闭、关闭总开关、非法事件、重启不恢复过期界面审批。
- 原生检查通过：中英文授权控件匹配、仅聊天文字不触发、同卡片去重、消失宽限、重新出现的新事件、读取失效清理，以及原有协议/音频/宠物/剪贴板回归。

### 真实授权验收

在本机实际触发计算器访问授权，提醒引擎记录了加入审批提醒、启动语音、用户接手，授权卡片随后消失。用户明确确认“听到了审批语音提醒”。正常无卡片时不产生该类提醒。

修复版已安装到现有软件并启用；原声音、规则、免打扰、昵称、扬声器、登录自启等设置保持。系统已重新登记同一应用的已有输入与识别权限。UI 识别只读，不自动允许或拒绝。
